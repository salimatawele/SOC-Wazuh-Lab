# Installation du Serveur Wazuh

## 1. Prérequis
- Machine virtuelle Linux (Ubuntu Server recommandé)
- Ressources : 2 vCPU, 4 Go RAM minimum.

## 2. Procédure d'installation
1. Mettre à jour le système :
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```
